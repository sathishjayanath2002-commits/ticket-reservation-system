# Cricket Ticket Reservation System

This is a shared Java Maven project built using NetBeans for our team assignment.

## 🌿 Branching Guidelines
* Do **NOT** commit straight to `main` or `develop`.
* Work exclusively on your individual feature branch (`feature/your-module`).
* Pull the latest updates from `develop` before pushing code.
* Always submit Pull Requests (PRs) targeting the **develop** branch.
